# Omomumi Faith Ayomikun, Student Portfolio

A responsive five-page student portfolio and academic planner built with HTML, CSS and JavaScript for COS 106.

## Structure

- `index.html`, welcome page
- `about.html`, education, career aspirations, skills and interests
- `projects.html`, sample project concepts
- `planner.html`, academic task planner
- `contact.html`, validated contact form demo
- `css/style.css`, shared responsive styles
- `js/script.js`, navigation, planner and form behavior
- `assets/`, portrait and audio player file

Open `index.html` in a browser or publish this folder with a static site host. Planner tasks are saved in the current browser. The contact form validates fields but does not send messages. Project entries are sample concepts.
